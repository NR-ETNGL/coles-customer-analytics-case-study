# Coles Group – Customer Analytics Case Study

Reproducible analysis pipeline for Individual Task 1 (Case Studies in Data Science, RMIT 2026). Predicts customer engagement / marketing-campaign response using Random Forest and SVM, trained on two public datasets, for the target role Data Scientist – Customer Analytics, Coles Group.

##Downloads two datasets:
- UCI Online Retail (541,909 UK e-commerce transactions, 2010–2011)
- Customer Personality Analysis (2,240 customers, marketing survey + campaign history)
## Cleans and engineers features (RFM features for Dataset 1; spend/tenure/campaign-history features for Dataset 2)
## Trains Random Forest and SVM classifiers on each dataset separately
## Reports Accuracy, Precision, Recall, F1 and ROC-AUC for every model
## Produces two figures: ROC curves and Random Forest feature importances

All numbers reproduce exactly what's reported in Section 3 (Data Analysis) of the report.
