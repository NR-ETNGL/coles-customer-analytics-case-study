# Coles Group – Customer Analytics Case Study

Analysis code for Individual Task 1 (Case Studies in Data Science, RMIT 2026).
Predicts campaign response / customer engagement using Random Forest and SVM
on two datasets: UCI Online Retail and Customer Personality Analysis.

## Files
- step1_retail_rfm.py — cleans Online Retail data, builds RFM features
- step2_cpa_features.py — cleans Customer Personality Analysis data
- step3_models.py — trains Random Forest + SVM, computes metrics
- step4_figures.py — generates ROC curve and feature importance figures
- results_summary.json — full metrics output
